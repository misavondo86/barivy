# Barivy - Website and Downloads

Barivy is a dynamic notch app for Windows, built independently
in WPF and C# by Daniel.

This repository contains ONLY the Barivy website, logo,
version.txt for update checks, and release downloads.
It does NOT contain Barivy source code, and it is NOT a fork
of Nusa or any other project. Barivy was built from scratch,
in a different language and codebase, inspired by the dynamic
notch concept.

Download Barivy from the Releases page.
Requirements: Windows 10/11 64-bit, .NET 10 Desktop Runtime.
